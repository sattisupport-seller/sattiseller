## Подготовка (накануне и за час)
1. Ноутбук заряжен, зарядка с собой.
2. **iPhone: выключить автообновление приложений** (Настройки → App Store → «Обновления ПО» — выкл.). Новая версия Expo Go может перестать открывать наш SDK 58. Проверено 28.11.2026: Expo Go из App Store (58.0.x) открывает SDK 58.
3. Включить точку доступа на iPhone, подключить к ней ноутбук.
4. Правило брандмауэра (один раз, PowerShell от имени администратора, из папки проекта):
   `powershell -ExecutionPolicy Bypass -File deploy\windows\demo-start.ps1 -FirewallOnly`
   Правило открывает порты 8000 и 8081 только для локальной подсети и работает, даже если Windows считает сеть «общественной».
5. Запуск сервера и Metro одной командой (обычный PowerShell, из папки проекта):
   `powershell -ExecutionPolicy Bypass -File deploy\windows\demo-start.ps1`
   Скрипт сам находит адрес ноутбука в точке доступа, отключает сон и показывает строку для Expo Go.
6. На iPhone: Expo Go → Enter URL manually → `exp://<адрес>:8081` (скрипт печатает точный адрес).
7. Аккаунт для встречи зарегистрирован; 5-минутная инструкция пройдена; в админке выданы «режим презентации» и доступ без подписки.
