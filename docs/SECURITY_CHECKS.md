# Проверки безопасности (К-2 п.6, 22.11.2026)

## Фаззинг OpenAPI (schemathesis 4.33.4)
Цель: локальный сервер (SQLite, без ИИ), схема `/v1/openapi.json`, 88 операций. Проверка: `not_a_server_error`.

Результаты:
- прогон на 3 652 запроса: 87 операций прошли, 1 не прошла (ST101);
- прогон на 9 057 запросов: та же одна операция, новых ошибок нет.

Разбор единственной ошибки:
- `POST /v1/auth/google` возвращает **503 `provider_not_configured`** («Вход через этого провайдера ещё не настроен»).
- Это намеренный ответ: вход через Google пока не настроен (нет аккаунта и ключей). Для проверки «не 500» это код 5xx, поэтому инструмент его считает ошибкой.
- Решение: принято как исключение, не дефект. Когда Google-вход будет настроен, код останется 503 только при отсутствии настройки; проверку пересмотреть.
- Другие предупреждения: 76 операций закрыты авторизацией (401/403), 2 операции отклоняют сгенерированные данные по валидации (схема и проверки API расходятся, поведение безопасное).

Не проверено: фаззинг с аутентификацией (нужны тестовые учётные записи и токены) — отдельным шагом на тестовом сервере.
