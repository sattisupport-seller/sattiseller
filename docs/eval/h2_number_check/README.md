# Независимая проверка чисел H2 (22.11.2026)

- `h2_recalc.py` — пересчёт метрик из сырых строк демо-магазина (заказы, продажи, возвраты, расходы, прибыль, закупка) по правилам описания приложения. Не импортирует код приложения, кроме чтения дампа.
- `verify_h2.py` — проверка каждого числа в ответах H2 (три прогона, отказы не проверяются): периоды по датам и словам, товары по названию, разницы и проценты между периодами.
- Дамп `h2_dump.json` получен временным тестом (`demo`-фикстура) и не хранится в репозитории; для повтора его нужно снова выгрузить.

Итог: 514 упоминаний чисел (437 метрик, 63 товарных, 14 без периода). Неверных — 0. Совпадение значений проверено автоматически; каждое несовпадение разобрано вручную.
