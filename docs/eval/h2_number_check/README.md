# Пересчёт чисел проверки H2

Скрипты читают прогоны из `server/tests/ai_eval_live_runs/` (не в git; путь считается от корня репозитория).

Нужно заранее: дамп данных магазина `h2_dump.json` (временный, не в git). Путь задаётся переменной окружения:

    SATTI_H2_DUMP=/путь/к/h2_dump.json python docs/eval/h2_number_check/verify_h2.py

Без переменной скрипт ищет `h2_dump.json` в текущей папке. Дамп выгружается заново из тестовой базы; старый не использовать.
