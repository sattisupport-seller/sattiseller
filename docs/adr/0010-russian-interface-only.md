# ADR 0010. Интерфейс приложения и ответы помощника — только на русском

Дата: 22.11.2026. Статус: принято (решение владельца, 22.11.2026, 19:06).

## Контекст
Пункт 4 MASTER_PLAN предусматривал интерфейс на русском и казахском. Казахский перевод работает некорректно: не проверен носителем, часть строк не переведена, помощник отвечал на казахском с ошибками. Владелец решил убрать казахский из приложения.

## Решение
1. Интерфейс приложения только на русском. Выбор языка в профиле и при создании магазина убран. Словарь `mobile/src/i18n/kk.ts` оставлен в репозитории, но не подключён; возврат — отдельным решением.
2. Черновики карточки товара и ответы покупателям — только на русском.
3. Помощник: вопросы на казахском понимаются (периоды, отказы), но ответ всегда по-русски. Проверка по периодам и отказам не меняется.
4. Тексты ошибок, письма (коды входа, служебные), уведомления и push — только русские. Казахские строки в словаре сервера (`errors.py`, `mailer.py`) не используются.
5. Материалы магазинов (store-listing) — только русский; проверка казахского носителем из OWNER_TODO снята.

## Последствия
- Казахский перевод не нужно проверять перед публикацией.
- Заменяет пункт 4 MASTER_PLAN («интерфейс — русский и казахский»). MASTER_PLAN не переписывается (файл владельца); отметка — в LAUNCH_PLAN.
- Тесты паритета ru/kk заменены проверкой одного языка и подключённого словаря.
- Для возврата казахского нужно: новый перевод с носителем, новое решение и обновление этого ADR.
