# ADR 0006 — тесты нажатий на экранах (1.11)

Дата: 21.11.2026. Статус: принято.

## Контекст

Тесты нажатий и форм не работали: `render` из `@testing-library/react-native` 14.1.0 с React 19.3 и Expo SDK 58
не давал запросов. Версии сверены: `npx expo install --check` — зависимости совпадают с SDK 58.

## Причина (найдена и проверена)

1. `render` в RNTL 14 возвращает промис. Результат становится доступен через `screen` только после `await`.
   Без `await` запросы падают с «`render` function has not been called», а `r.getByRole` не существует.
2. Состояние React обновляется асинхронно. Проверки после `fireEvent` — через `waitFor`, иначе видно старое состояние.
3. Кнопка `Button` до нажатия вызывает `expo-haptics`; в тестах модуль нужно замокать.
4. Текст экранов берётся из словаря по локали сессии: в моке сессии нужен `locale: 'ru'`, иначе вместо текста видны ключи.

Решение: `await render(...)`, запросы через `screen`, проверки через `waitFor`, мок `expo-haptics`, `locale` в моке сессии.

## Что сделано

- `src/__qa__/interactions.test.tsx`: галочка согласия на входе, ссылки на политику и условия, экран повторного согласия (1.19).
- `src/__qa__/flows.test.tsx`: удаление аккаунта (код, 6 цифр, выход, переход), подключение Kaspi (флаг, пустые поля, успешное подключение).
- Всего 125 тестов, все проходят.

## Покрытие

Строки в `src/app`: было 48,8%, стало 50,5%. Цель 70% не достигнута. Не покрыты экраны с большими формами и списками:
импорт (`import.tsx`, 295 строк), затраты и комиссии, помощник, подписка, экспорт, карточки товара и заказа.
