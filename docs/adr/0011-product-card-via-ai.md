# ADR 0011. Карточка товара через ИИ (живая модель с фото)

Дата: 22.11.2026. Статус: принято (решение владельца, 22.11.2026, 19:10). Заменяет прежнее решение «черновики описаний по правилам, без модели».

## Контекст
Черновик описания работал по шаблону: названия и описание собирались из строк продавца, без модели. Владелец решил сделать составление карточки с помощью ИИ доступным сейчас. Ответы покупателям остаются шаблоном (см. BACKLOG).

## Решение
1. `/ai/product-drafts` использует ту же живую модель, что и помощник (переменная `SATTI_AI_MODEL`). Фото товара передаются модели, если она их принимает (проверено: `claude-haiku-5-5` принимает JPEG, PNG, WebP).
2. Результат только на русском: 3 названия, описание, характеристики.
3. Правила для модели: только факты из текста продавца и то, что явно видно на фото; неизвестное — «Уточнить»; не выдумывать характеристики, числа, бренд, «оригинал», «гарантию»; без контактов и ссылок.
4. Проверка кодом после модели: 3 названия не длиннее 60 знаков; каждое число — из фактов продавца; ссылки и контакты запрещены; слова «оригинал», «гарантия» допускаются только если есть в фактах; ответ на русском. Не прошёл проверку — черновик пересобирается по шаблону, с пометкой причины.
5. Маскировка данных — как у помощника: телефоны, почта и адреса в фактах заменяются до отправки модели.
6. Пометка «Черновик ИИ — проверьте перед публикацией». Квота, бюджет, выключатель и согласие — как у помощника. Черновик тратит 1 единицу дневной квоты (30).
7. Запасной вариант шаблона: выключатель, исчерпанный бюджет, сбой или ответ модели, не прошедший проверку — шаблон с понятной пометкой о причине. Ответ пользователю при этом не теряется.
8. Фото не сохраняются на сервере Satti (живут в памяти запроса), но уходят в ИИ-сервис в США. Текст согласия дополнен (ждёт одобрения владельца; юридические формулировки не утверждены).

## Проверка
- Тесты на моке: проверка кодом (числа, ссылки, контакты, выдуманные утверждения, язык, формат), вызов с фото и маскировкой, учёт стоимости, шаблон при сбое, выключателе и бюджете.
- Живая проверка 22.11: 10 товаров (5 с фото, 5 без). Все 10 прошли проверку кодом. Стоимость партии $0,00517, около $0,0005 за карточку (бюджет $0,30). Тексты просмотрены вручную: выдуманных характеристик и чисел не найдено.

## Ограничения
- Проверка кодом не ловит выдуманные характеристики без чисел и без слов из списка (например, «натуральная кожа» для кожаного изделия). Поэтому пометка «проверьте перед публикацией» обязательна.
- Фото проверялись синтетические (рисованные силуэты) — проверка на реальных фото товаров в приложении ещё нужна.
