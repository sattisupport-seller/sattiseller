# ADR 0002 — мобильное приложение и API

Статус: принято (19 ноября 2026).

## Контекст

ТЗ (docs/spec.md, раздел 4 и 16) описывает переход от веб-прототипа версии 1.2 к нативному приложению на Expo и JSON API сервера. По решению владельца проект ведётся с нуля: код версии 1.2 не переносится.

## Решения

1. **Сервер:** Python 3.12, FastAPI, Pydantic. Flask не используется, потому что проект новый. SQLAlchemy 2 и Alembic подключаются, когда появятся модели данных (задача 4+).
2. **Приложение:** Expo SDK 58 (React Native 0.88), TypeScript strict, Expo Router, шрифт Inter, иконки Lucide.
3. **Деньги:** целые тиыны, ставки в базисных пунктах, округление ROUND_HALF_UP. Модуль `server/app/money.py`, формулы — `server/app/finance.py`.
4. **Золотые тесты:** `server/tests/test_golden.py` с ожидаемыми значениями из ТЗ (G001–G008, R001–R003). Ожидаемые значения не подгонялись под код.
5. **Расположение:** `server/` и `mobile/` в одном репозитории; документация в `docs/`.

## Известные отклонения

- В `mobile/` установлен `lucide-react-native` с флагом `--legacy-peer-deps`: при обычной установке npm не может разрешить конфликт транзитивных peer-зависимостей Expo (react-dom 19.3.1 против react 19.3.0). `expo-doctor` при этом проходит 20/20. Проверить после обновления SDK.
- Миграции БД (`server/migrations/`) пока пусты.

## Последствия

Этапы A–B из ТЗ не требуют переписывания при переходе на PostgreSQL: деньги уже в целых числах, а `money.py` не зависит от БД.
