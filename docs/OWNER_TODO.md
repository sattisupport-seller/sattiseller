# Что сделать владельцу (по порядку)

Основа — MASTER_PLAN раздел 7.1. Для каждого пункта: зачем, шаги для Windows, стоимость, что разблокирует. Цены — на момент написания, уточняйте на сайте сервиса. Пароли, ключи и токены в чат не присылайте: вписываете их в `.env` сами.

## 1. Почта проекта
- **Зачем:** отдельный адрес для аккаунтов сервисов (Expo, GitHub, Google Play, Apple).
- **Шаги:** создайте Gmail-ящик. В «Управление аккаунтом Google → Безопасность» включите двухфакторную защиту.
- **Стоимость:** бесплатно.
- **Разблокирует:** пункты 2, 5, 7, 10.

## 2. GitHub
- **Зачем:** удалённый репозиторий, CI, копии кода.
- **Шаги:** github.com → Sign up с почтой из пункта 1 → Settings → Password and authentication → двухфакторная защита. Затем New repository: имя `sattiseller`, Private, без README и .gitignore (фактически создан с этим именем). Пришлите адрес `https://github.com/<логин>/satti-seller` в чат.
- **Стоимость:** бесплатно (приватный репозиторий).
- **Разблокирует:** push после каждого этапа, CI, слияние в `feature/bootstrap` (6.7).

## 3. Docker Desktop
- **Зачем:** запуск всей системы локально одной командой (Compose).
- **Шаги:** docker.com/products/docker-desktop → установщик, запустить от администратора → перезагрузить ПК → открыть Docker Desktop и принять условия. Проверка в PowerShell: `docker --version`.
- **Стоимость:** бесплатно для личного использования; для компаний — по условиям Docker.
- **Разблокирует:** 4.1 (запуск Compose), проверку 4.5–4.7.

## 4. Android Studio и эмулятор
- **Зачем:** Maestro-сценарии, скриншоты, ручная проверка на эмуляторе.
- **Шаги:** developer.android.com/studio → установщик от администратора → «Standard» → SDK Manager: Android 15 (API 35) и «Android SDK Platform-Tools». Device Manager → Create device → Pixel 7 с Google Play. Проверка: `adb --version`.
- **Стоимость:** бесплатно.
- **Разблокирует:** 5.3, 5.10, ручную часть 5.11.

## 5. Аккаунт Expo
- **Зачем:** сборки приложения в облаке (EAS Build).
- **Шаги:** expo.dev → Sign up. Затем вы сами в PowerShell в папке `mobile`: `npx eas-cli@latest login`. Логин и пароль в чат не присылайте.
- **Стоимость:** бесплатный план (есть лимит сборок в месяц).
- **Разблокирует:** 5.1 (сборка), установку на ваш телефон.

## 6. Ключ Anthropic
- **Зачем:** живой ИИ-помощник и оценка качества.
- **Шаги:** console.anthropic.com → Sign up → Billing → пополнить баланс → Settings → Limits: месячный лимит расходов → API Keys → Create key. Ключ вписываете в `server\.env` как `ANTHROPIC_API_KEY=...`.
- **Стоимость:** оплата за использование; зависит от модели и объёма.
- **Разблокирует:** 3.5 (живой ИИ), 3.8 (оценка ≥ 90%), проверку маскировки на реальном запросе.

## 7. Google Play Console
- **Зачем:** публикация Android, вход через Google, подписка, закрытый тест.
- **Шаги:** play.google.com/console → Sign up с почтой из пункта 1 → оплатить регистрацию → подтвердить личность (несколько дней). Найти 12 тестировщиков на Android для закрытого теста на 14 дней (5.6).
- **Стоимость:** 25 $ один раз.
- **Разблокирует:** 3.1 (покупки), 3.2 (RTDN), 3.3 (вход через Google), 5.4–5.6.

## 8. Сервер и домен в Казахстане, второе хранилище для бэкапов
- **Зачем:** боевой сервер (серверы и базы — только в Казахстане, ADR-0005), домен для HTTPS, копии бэкапов.
- **Шаги:** выбрать хостинг с датацентром в Казахстане; VPS Ubuntu 24.04, от 2 ГБ памяти, SSD. Домен у регистратора. Второе хранилище: S3-совместимое (например, Backblaze B2 или Cloudflare R2): создать bucket и ключ доступа. SSH-ключ создаёте сами (`ssh-keygen -t ed25519`), приватный ключ никому не передаёте. В чат — IP сервера и домен.
- **Стоимость:** уточнить у провайдеров; домен — порядка 10–20 $ в год.
- **Разблокирует:** 4.3 (deploy.sh), 4.6 (HTTPS), 4.7, учения восстановления на сервере, `SATTI_PUBLIC_BASE_URL`, нагрузку 1.16 и 1.17 на сервере.

## 9. Почтовый сервис (SMTP)
- **Зачем:** коды входа и удаления, письма о хранении, оповещения.
- **Шаги:** выбрать сервис (например, Postmark или Mailgun), создать SMTP-учётные данные. Для домена добавить DNS-записи SPF, DKIM, DMARC (точные значения даст Claude Code после выбора сервиса). В `server\.env`: `SATTI_SMTP_HOST`, `SATTI_SMTP_PORT`, `SATTI_SMTP_USER`, `SATTI_SMTP_PASSWORD`.
- **Стоимость:** от нуля до нескольких долларов в месяц при малом объёме.
- **Разблокирует:** 3.6 (отправка), дозавершение 1.4 (письмо владельцу при 80% бюджета), проверку доставки.

## 10. Apple Developer
- **Зачем:** App Store, вход через Apple, TestFlight.
- **Шаги:** developer.apple.com → Enroll (Apple ID с двухфакторной защитой), оплатить 99 $ в год. Ключи (Sign in with Apple, App Store Connect API) создаёте сами; файлы `.p8` храните вне проекта, в `.env` — только путь.
- **Стоимость:** 99 $ в год.
- **Разблокирует:** 3.1, 3.2, 3.3, TestFlight (5.6), 5.7.

## 11. Firebase (пуши на Android)
- **Зачем:** пуш-уведомления на Android.
- **Шаги:** console.firebase.google.com → Add project → Android-приложение с package `kz.satti.seller` → скачать `google-services.json` и сообщить Claude Code, где лежит.
- **Стоимость:** бесплатный план.
- **Разблокирует:** 3.4 (пуши) на Android.

## 12. Ответ Kaspi и токен тестового магазина
- **Зачем:** реальная проверка интеграции (сейчас этап 2 на моках).
- **Шаги:** сверьтесь с официальной документацией Kaspi Shop API (guide.kaspi.kz/partner/ru/shop/api); при необходимости обратитесь в Kaspi. Для теста — токен тестового магазина, который создаёт сам продавец в кабинете. Токен вводите в приложении сами, не в чат.
- **Стоимость:** уточнить у Kaspi.
- **Разблокирует:** реальную проверку 2.1–2.8 и сверку прибыли с кабинетом.

## 13. ИП
- **Зачем:** приём оплаты и договоры с магазинами.
- **Шаги:** регистрация через eGov / налоговый кабинет. Название ИП и БИН вписываются в переменные, не в тексты.
- **Стоимость:** уточнить (госпошлина и взносы по текущим правилам).
- **Разблокирует:** приём оплаты; обновление документов через переменные.

## 14. Юрист
- **Зачем:** проверка политики, условий, согласий и уведомления уполномоченного органа о начале обработки персональных данных.
- **Шаги:** найти юриста по персональным данным в Казахстане; передать `docs/legal/` и раздел 4 `docs/MASTER_PLAN.md`; ответы — в `docs/PROPOSALS.md`.
- **Стоимость:** по договорённости.
- **Разблокирует:** публикацию; 1.19 (новая версия документов — повторные согласия); 4.8.

## 15. Проверка казахского перевода носителем
- **Зачем:** перевод сделан без носителя языка (`docs/i18n-kk-review.csv`).
- **Шаги:** найти носителя казахского языка; он отмечает строки в CSV; файл передаётся Claude Code.
- **Стоимость:** по договорённости.
- **Разблокирует:** закрытие предупреждения о переводе перед магазинами.

## 16. Хранение `secret_key` и ключа бэкапов
- **Зачем:** без `secret_key` сессии и хеши не сойдутся; без ключа бэкапов копии не открыть.
- **Шаги:** после первого запуска сервера скопируйте `server\data\secret_key` в менеджер паролей (как файл). Ключ бэкапов `SATTI_BACKUP_KEY` (из `python scripts/backup.py genkey`) — тоже туда. Не класть в git и в чат.
- **Стоимость:** бесплатно (встроенный менеджер или KeePass).
- **Разблокирует:** безопасный запуск и восстановление (4.5).
