## Описание (начало)
Satti Seller показывает, сколько вы зарабатываете на каждом товаре после закупки, комиссии и доставки. Видно, какие товары продаются в минус и каких данных не хватает для точного расчёта. Помощник отвечает на вопросы о магазине и объясняет, почему изменилась прибыль. Ответы создаёт ИИ и они могут быть неточными: проверяйте важные цифры в карточках товаров и заказов. Попробуйте на демо-магазине без регистрации. Satti Seller — независимый сервис, не связан с Kaspi.kz.

## Заметка для проверяющих
- Как попробовать без входа: «Попробовать на демо-магазине» на первом экране.
- Аккаунт для проверки: нужен отдельный email с фиксированным кодом. Не создан (владелец).
- Помощник: перед первым вопросом показывается экран согласия на передачу данных ИИ-сервису (Anthropic, США) с кнопками «Разрешить» и «Не сейчас»; без согласия помощник не работает, остальное приложение работает; отозвать согласие — в профиле. Ответы помечены «Бета · ответ создан ИИ и может быть неточным»; у каждого ответа есть 👍/👎 и «Пожаловаться».
- Склад: остатки вносит продавец; снятие с продажи — только с подтверждением.
- Подключение Kaspi по API выключено по умолчанию (флаг kaspi_connection).
- Приложение не связано с Kaspi.kz; упоминания Kaspi — только по смыслу.

## Для проверяющих Apple (5.8): экран согласия на ИИ
- Где: вкладка «Помощник» → задайте любой вопрос (или нажмите пример). До первого вопроса показывается экран согласия «Помощник использует ИИ»: какие данные передаются, кому (Anthropic, США), кнопки «Разрешить» и «Не сейчас».
- Без согласия помощник не работает, остальные разделы приложения работают. Отозвать согласие — в профиле.
- Скриншот экрана согласия: **не приложен** — его нужно снять на устройстве (сборка Expo Go или TestFlight). Положить в `docs/store-screenshots/consent.png` до отправки.

- Қысқа сипаттама (80 таңбаға дейін): «Әр тауардың пайдасы, тапсырыстар және сатушыға арналған ЖИ-көмекші»
- Сипаттама: Satti Seller әр тауардан сатып алу, комиссия және жеткізуден кейін қанша тапқаныңызды көрсетеді. Қай тауар залалға жұмыс істейтінін және дәл есеп үшін қандай деректер жетіспейтінін көресіз. Көмекші дүкен туралы сұрақтарға жауап береді және пайданың неге өзгергенін түсіндіреді. Жауаптарды ЖИ жасайды, олар дәл болмауы мүмкін: маңызды сандарды тауар мен тапсырыс карточкаларында тексеріңіз. Тіркеусіз демо-дүкенде көріп көріңіз. Satti Seller — тәуелсіз қызмет, Kaspi.kz-пен байланысы жоқ.
