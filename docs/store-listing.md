## Описание (начало)
Satti Seller показывает, сколько вы зарабатываете на каждом товаре после закупки, комиссии и доставки. Видно, какие товары продаются в минус и каких данных не хватает для точного расчёта. Помощник отвечает на вопросы о магазине и объясняет, почему изменилась прибыль. Ответы создаёт ИИ и они могут быть неточными: проверяйте важные цифры в карточках товаров и заказов. Попробуйте на демо-магазине без регистрации. Satti Seller — независимый сервис, не связан с Kaspi.kz.

## Заметка для проверяющих
- Как попробовать без входа: «Попробовать на демо-магазине» на первом экране.
- Аккаунт для проверки: нужен отдельный email с фиксированным кодом. Не создан (владелец).
- Помощник (К-24, 27.11): согласие на передачу данных ИИ-сервису (Anthropic, США) — в галочке на экране входа, до создания аккаунта: «Я принимаю условия использования и политику конфиденциальности, включая передачу данных ИИ-сервису» и отдельной строкой рядом «Помощник и карточки товаров работают на ИИ компании Anthropic (США). Данные покупателей перед отправкой скрываются.» Без галочки вход невозможен. Отдельного экрана перед помощником нет. Демо-магазин (вымышленные данные, без входа) — помощник работает сразу. Ответы помечены «Бета · ответ создан ИИ и может быть неточным»; у каждого ответа есть 👍/👎 и «Пожаловаться».
- Склад: остатки вносит продавец; снятие с продажи — только с подтверждением.
- Подключение Kaspi по API выключено по умолчанию (флаг kaspi_connection).
- Приложение не связано с Kaspi.kz; упоминания Kaspi — только по смыслу.

## Для проверяющих Apple (5.1.2(i)): где пользователь разрешает передачу данных ИИ
- Где: экран входа (почта, Apple или Google). Галочка «Я принимаю условия использования и политику конфиденциальности, включая передачу данных ИИ-сервису» и строка под ней: «Помощник и карточки товаров работают на ИИ компании Anthropic (США). Данные покупателей перед отправкой скрываются.» Без галочки кнопки входа не работают.
- Уже зарегистрированные пользователи после обновления один раз видят экран «Обновление условий» с той же галочкой и строкой (версия условий 2026-11-27-1).
- Данные покупателей (имена, телефоны, адреса) скрываются до отправки — код, не настройка.
- Скриншот экрана входа с галочкой: **не приложен** — снять на устройстве, положить в `docs/store-screenshots/consent.png`.
