## App Store
- Название: Satti Seller (проверить доступность)
- Подзаголовок (до 30 знаков): «Прибыль и заказы продавца» — 25 знаков

- Категория: Бизнес
- Метка конфиденциальности: email, содержимое пользователя (импорт затрат, вопросы помощнику, фото для черновиков), данные использования и диагностика — «для работы приложения», не для отслеживания

## Google Play
- Краткое описание (до 80 знаков): «Прибыль по каждому товару, заказы и ИИ-помощник для продавца маркетплейса» — 73 знака
- Форма «Безопасность данных»: те же данные, что в метке Apple; данные передаются по HTTPS; пользователь может запросить удаление (в приложении есть удаление аккаунта)

## Описание (начало)
Satti Seller показывает, сколько вы зарабатываете на каждом товаре после закупки, комиссии и доставки. Видно, какие товары продаются в минус и каких данных не хватает для точного расчёта. Помощник отвечает на вопросы о магазине и объясняет, почему изменилась прибыль. Попробуйте на демо-магазине без регистрации. Satti Seller — независимый сервис, не связан с Kaspi.kz.

## Заметка для проверяющих
- Как попробовать без входа: «Попробовать на демо-магазине» на первом экране.
- Аккаунт для проверки: нужен отдельный email с фиксированным кодом (на сервере — только для этого адреса и окружения). Не создан.
- Помощник: перед первым вопросом показывается согласие на передачу данных ИИ-сервису.
- Подключение Kaspi в этой версии выключено (флаг kaspi_connection = false).
- Приложение не связано с Kaspi.kz; упоминания Kaspi — только по смыслу.
