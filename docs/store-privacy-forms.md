# Анкеты приватности и рейтинг (5.4) — текущее состояние

Черновик для заполнения владельцем в App Store Connect и Google Play Console. Обновлено 22.11.2026: помощник включён по умолчанию (решение владельца), передача данных ИИ-сервису заявлена ниже. Текст согласия и юридические формулировки — черновик, на одобрении владельца.

## Что приложение собирает (по коду)

| Данные | Зачем | Где хранится | Отслеживание |
|---|---|---|---|
| Email | вход по коду и через Apple/Google | сервер (PostgreSQL) | нет |
| Имя или идентификатор входа Apple/Google | вход | сервер | нет |
| Данные магазина: товары, закупочные цены, расходы, импорт затрат | расчёт прибыли | сервер | нет |
| Содержимое, которое пользователь вводит (фото для черновиков описаний) | черновики | сервер | нет |
| Токен сессии | вход | Keychain / Keystore (expo-secure-store) | нет |
| Данные использования: счётчики по дням и названиям разделов, без пользователя и устройства (3.9) | улучшение экранов | сервер | нет |
| Ошибки приложения и сервера (без персональных данных в тексте) | диагностика | сервер (журнал ошибок) | нет |

Не собирается: геопозиция, контакты, фото из галереи без выбора пользователя, микрофон, реклама, рекламные идентификаторы, аналитические SDK сторонних сервисов, push-токены (expo-notifications в приложении нет).

Данные покупателей Kaspi (имена, телефоны, адреса) приложением не собираются и не хранятся.

## Apple App Privacy (текущее состояние)

- Данные, связанные с пользователем: контактная информация (email), идентификаторы (ID входа), содержимое пользователя (импорт затрат, фото), финансовая информация (данные о продажах и затратах магазина, введённые продавцом).
- Данные не используются для отслеживания. Отслеживания нет.
- Цель: функциональность приложения; аналитика — только внутренняя, без привязки к пользователю.

## Google Play Data safety (текущее состояние)

- Собираемые типы: email, идентификаторы, фото (по выбору пользователя), финансовые сведения магазина, данные использования и диагностика.
- Данные передаются по HTTPS. Пользователь может запросить удаление данных; в приложении есть удаление аккаунта.
- ИИ-помощник (после согласия): текст вопроса, сводные цифры магазина за период, названия товаров, история диалога передаются ИИ-сервису Anthropic (США). Телефоны, адреса и имена покупателей не передаются. Хранится: вопрос с маскировкой, признак отказа и оценка 👍/👎/жалоба (для качества). Согласие отзывается в профиле.
- Данные не продаются. Данные не передаются третьим лицам, кроме инфраструктуры хостинга и ИИ-сервиса Anthropic (см. пункт выше; указать провайдеров при заполнении).

## Рейтинг возраста

- Насилие, сексуальный контент, азартные игры, использование алкоголя и табака: нет.
- Пользовательский контент, общение между пользователями: нет. Вопросы помощнику — это ввод пользователя в ИИ-сервис, не общение между пользователями; ответы генерирует ИИ (указано в описании и помечено «Бета · ответ создан ИИ»).
- Ориентировочно: 4+ (App Store) и «Для всех» (Google Play). Итоговый ответ — владелец в анкете.

## Что владельцу проверить перед отправкой

1. Провайдера хостинга и страну хранения данных (для Data safety).
2. Что политика конфиденциальности (docs/legal) совпадает с этим списком.
3. Дату последнего обновления анкет (22.11.2026) и что анкеты учитывают помощника.
