А3. Режим презентации — пример остатков и себестоимости
- Включается владельцем в админке для конкретного аккаунта. У обычных продавцов всё как решено в К-24: остаток вводится вместе с себестоимостью.
- Пример остатков — из его товаров и продаж: запас примерно на 30 дней продаж; несколько товаров с остатком 0–1, чтобы показать автоснятие. Пример себестоимости — одно число «≈ 60 % от цены», меняется прямо на встрече. Везде пометка «пример»; продавец может заменить своими цифрами.
- Все инструменты работают на его данных, чтобы он испробовал всё: утечки маржи, минимальная цена, пороги доставки, плательщик НДС, буфер, предпросмотр автоснятия, ИИ-карточка по фото, ИИ-помощник по его цифрам, шаблоны ответов. В его магазине Kaspi ничего не меняется.

А4. Остатки — правила боевого режима
- Метода изменить остаток в API Kaspi нет: только прайс-лист (`stockCount`; Kaspi забирает его примерно раз в час) и кабинет. При заказе Kaspi уменьшает остаток сам.
- Отмена (гид q3694): при своей доставке и самовывозе Kaspi возвращает остаток сам; при Kaspi Доставке в статусах «Новые», «На подписании», «Предзаказ», «Упаковка» — тоже сам; после «Передача» / «Передан на Kaspi Доставку» — не возвращает: продавец забирает товар в пункте приёма и вносит остаток вручную. У нас так же: такой товар — «едет обратно», в остаток только после подтверждения продавца «забрал». Возврат — так же, плюс выбор «годен к продаже / брак».
- Риск: прайс со старым остатком «вернёт» проданную единицу → повторная продажа → отмена «нет в наличии» = отмена по вине продавца (порог Kaspi — меньше 3 %, иначе ограничения вплоть до отключения); правило 1.10 запрещает выставлять товар, которого нет.
- Инвариант: прайс никогда не показывает остаток больше, чем «последний известный остаток − все известные заказы − товары, которые едут обратно». Перед выдачей прайса — досинхронизировать заказы с ограничением по времени; не успели — отдать последний корректный прайс, остаток не завышать. Тест «гонки»: заказ между нашей синхронизацией и запросом прайса не возвращает остаток.
- Буфер автоснятия на товар, по умолчанию 0. Подсказки продавцу: «Kaspi обновляет наличие по прайсу примерно раз в час»; «после подключения прайса меняйте остатки только в Satti Seller — правки в кабинете Kaspi перезапишутся». Проверить несколько складов (`storeId`).
