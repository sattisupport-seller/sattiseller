## К-12 · 22.11.2026 · Ошибка «Описание товара» (после текущих К-8…К-10)

Владелец в демо (Expo Go) нажимает «Описание товара» — получает ошибку. Координатор прочитал код, вероятные причины:

3. Понятные тексты для каждой ошибки черновика (согласие, квота, выключатель, формат фото) — не код и не «HTTP 403».
Сначала воспроизведи ошибку на запущенном сервере по журналу запросов (какой код вернулся), затем исправь все три пункта. Тесты: длинная первая строка с числами около 60-го символа; черновик без согласия; jest на показ согласия. Причину, которую увидел в журнале, запиши в REPORT.
