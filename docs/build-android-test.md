# Тестовая сборка Android через бесплатный аккаунт Expo

Цель: получить APK (файл установки) для телефона Android, без Android Studio и без платных аккаунтов.
Сборка идёт в облаке Expo. Бесплатный план даёт ограниченное число сборок в месяц — этого хватает для проверки.

## Что понадобится

- Компьютер с проектом `satti-seller` (папка `mobile`).
- Бесплатный аккаунт на https://expo.dev (почта и пароль).
- Телефон Android с доступом в интернет.
- Адрес сервера, до которого телефон дотянется **из интернета** (не 172.20.10.2 — это локальная сеть). Пока сервер не размещён (задача 22), см. раздел «Ограничения».

## Шаг 1. Установить инструмент сборки

В терминале (PowerShell) из папки `mobile`:

```powershell
cd "C:\Users\user\Desktop\satti-seller\mobile"
npx -y eas-cli@latest --version
```

Первый запуск скачает EAS CLI. Ничего глобально устанавливать не нужно.

## Шаг 2. Войти в аккаунт Expo

```powershell
npx -y eas-cli@latest login
```

Введите почту и пароль от expo.dev. Проверка:

```powershell
npx -y eas-cli@latest whoami
```

## Шаг 3. Подключить проект к Expo (один раз)

```powershell
npx -y eas-cli@latest init
```

Команда создаст проект в аккаунте и добавит в `app.json` идентификатор (`extra.eas.projectId`). Этот файл потом закоммитьте.

## Шаг 4. Указать адрес сервера для тестовой сборки

Откройте `mobile/eas.json` и в профиле `preview` замените `https://REPLACE-WITH-TEST-SERVER/v1` на адрес тестового сервера с `/v1` в конце.
Пока адреса нет, сборка соберётся, но приложение не сможет работать с сервером (можно будет только посмотреть экраны).

## Шаг 5. Собрать APK

```powershell
npx -y eas-cli@latest build --platform android --profile preview
```

- Спросит, создать ли ключ подписи Android: ответьте **Yes** (ключ хранится в Expo, это нормально для тестов).
- Сборка идёт 10–20 минут. Ход виден в терминале и на expo.dev.
- В конце появится ссылка и QR-код на APK.

## Шаг 6. Установить на телефон

1. Откройте ссылку или отсканируйте QR-код **на телефоне Android**.
2. Скачайте APK.
3. Разрешите установку из этого источника (Настройки → Приложения → Браузер/Файлы → Установка неизвестных приложений).
4. Установите и откройте «Satti Seller».

## Шаг 7. Что проверить на телефоне

- Запуск и экран запуска (зелёный фон `#6366F1`, знак по центру).
- «Демо» на экране входа: работает без почты и без сервера входа.
- Обзор, прибыль, заказы, товары, помощник (вопросы в демо).
- Профиль → «Налог», «Скачать мои данные» (откроется меню «Поделиться»).

Сообщите, что не работает: скриншот и текст ошибки. Ошибки также собираются на сервере (раздел «Ошибки» в админ-панели, если сервер доступен).

## Ограничения сейчас

- **Вход через Apple и Google** работает только с идентификаторами приложения у провайдеров (задача 21): без аккаунтов Apple Developer и Google Cloud вход не проверяется. Для тестов используйте демо.
- **Вход по коду на почту** в сборке выключен (`EXPO_PUBLIC_EMAIL_LOGIN=0`); письма с кодами пока не отправляются за пределы папки `outbox`.
- **Сервер** должен быть доступен из интернета. Для тестов можно поднять туннель, но адрес будет меняться. Постоянный тестовый сервер — задача 22 (аккаунт хостинга и домен).
- **Подпись:** APK подписан ключом Expo, не годится для публикации в Google Play. Для магазина нужна отдельная сборка `production` и аккаунт Google Play (задача 32).

## Если что-то пошло не так

- Ошибка сборки: откройте ссылку из терминала, там лог сборки. Пришлите последние 30 строк.
- Нет установки на телефоне: проверьте разрешение на установку из неизвестного источника.
- Приложение открывается, но сервер не отвечает: проверьте адрес в `eas.json` (`https`, `/v1` в конце) и доступность сервера с телефона через браузер.
