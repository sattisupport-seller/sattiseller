## Порядок и зависимости

1. Этап 1 — независимые задачи; 1.7 (PostgreSQL) блокирует 4.5 и нагрузку.
2. 1.10 (бэкапы) нужен до 4.5.
3. Этап 2 — не зависит от 1.x, кроме 1.1 и 1.7 (шифрование токенов зависит от ключа сервера).
4. Этап 3 — почти полностью требует ключи; код и моки делаются сейчас.
5. Этап 4 — требует 1.7, 3.7; запуск — только на сервере.

## Риски

- Docker Desktop и Android Studio требуют прав администратора; без них Compose и Maestro только написаны, не запущены.
- Документация Kaspi Shop API — проверять через официальный сайт; допущения записываются в `docs/kaspi-assumptions.md`.
- Изменение схемы под PostgreSQL может сломать тесты на SQLite — тесты гоняются на обеих базах.

## Критерии готовности (этап)

- Все тесты сервера и приложения зелёные; линтер без замечаний; `tsc` без ошибок.
- Критичные модули сервера ≥ 90%, экраны приложения ≥ 70%.
- Нагрузка 100 пользователей без 5xx (или объяснено, что мешает).
- Коммит на каждый законченный шаг; копия `git bundle` после этапа.
