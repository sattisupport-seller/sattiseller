## Вопрос: закрытая бета без Kaspi API — на импорте из кабинета продавца (Excel/CSV)?

**Можно, но не в нынешнем виде.** Что уже есть: импорт закупочных цен (XLSX/CSV, сопоставление колонок, проверка, применение, отмена), прибыль по товарам, налог, расходы, экспорт. Чего не хватает:

1. **Импорта заказов.** Сейчас импорт понимает только закупочные цены. Прибыль считается по заказам, а заказы в бете без API приходят только из выгрузки кабинета. Нужен импорт выгрузки заказов (номер, дата, статус, товар, количество, сумма, комиссия, доставка, возвраты).
2. **Образцов файлов.** Нужны настоящие выгрузки из кабинета Kaspi (заказы, товары, возвраты) с вашими названиями колонок. Без них формат угадывается, и расчёт может быть неверным.
3. **Периодичности.** Без API данные актуальны только на день загрузки; пользователь должен загружать файлы вручную. Это ограничение записать в бета-инструкции.
4. **Согласования с Kaspi.** Использовать выгрузку продавца для расчётов в сторонней программе — условия пользования кабинетом не проверены. Это к юристу и вопрос к Kaspi (`docs/owner.md` или ТЗ 2.1, приложение Д).
5. **Тестов импорта заказов** и сверки «выгрузка → прибыль» на образце (без них нельзя обещать точность).

Предлагаю: добавить этап 1.18 «импорт заказов из выгрузки кабинета» после получения образцов от вас; до этого бета возможна только с демо и импортом закупок.
