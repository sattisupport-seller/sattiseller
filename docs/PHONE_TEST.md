# Проверка помощника на своём телефоне (без публикации)

Цель: за 15 минут увидеть помощника на телефоне. Ноутбук **не открывать в интернет**: телефон и ноутбук должны быть в одной сети (Wi‑Fi или раздача интернета с телефона).

## Что понадобится
- Ноутбук с проектом `satti-seller` и настроенным сервером (`server/.env` с ключом `ANTHROPIC_API_KEY`, и `SATTI_AI_LIVE=1`).
- Телефон: iPhone или Android, установлено приложение **Expo Go** (App Store / Google Play).

## Шаг 1. Запустить сервер на ноутбуке
В PowerShell:
```
cd C:\Users\user\Desktop\satti-seller\server
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Если Windows спросит про доступ к сети — разрешите **только для частной сети**.

## Шаг 2. Узнать IP ноутбука
В другом окне PowerShell: `ipconfig` → строка «IPv4-адрес» активного Wi‑Fi (например `192.168.0.10`).

## Шаг 3. Запустить приложение для Expo Go
```
cd C:\Users\user\Desktop\satti-seller\mobile
$env:EXPO_PUBLIC_API_URL="http://192.168.0.10:8000/v1"; npx expo start
```
Подставьте свой IP. Появится QR-код. Откройте его камерой (iPhone) или сканером Expo Go (Android).

## Шаг 4. Войти и попробовать помощника
1. На первом экране нажмите «Попробовать на демо-магазине».
2. Откройте вкладку «Помощник» → экран согласия → «Разрешить» (без согласия помощник не работает, остальное приложение работает).
3. Спросите: «сколько прибыли за 14 дней», «кеше таза пайда қанша болды», «что скоро закончится на складе».
4. Проверьте: метка «Бета · ответ создан ИИ и может быть неточным», кнопки 👍 / 👎 и «Пожаловаться» под ответом, остаток дневной квоты вверху.

## Шаг 5. Сравнить цифры с экранами
Откройте «Обзор» или «Прибыль» за тот же период и сверьте прибыль и заказы с ответом помощника.

## Шаг 6. Жалобы и оценки в админке
Откройте в браузере на ноутбуке `http://localhost:8000/admin` (телефон не нужен). Вход — по email владельца и коду двухфакторной защиты. В разделе «Жалобы и 👎» появятся ваши оценки.

## Шаг 7. Выключатель помощника
В админке в разделе «Флаги» выключите `ai_assistant` → в приложении у помощника появится сообщение «Помощник временно недоступен», остальное работает. Включите обратно — помощник вернётся.

## Если что-то не работает
- Экран «Не удаётся подключиться»: проверьте, что телефон и ноутбук в одной сети, IP в шаге 3 верный, сервер запущен, брандмауэр разрешил порт 8000.
- Ответ «Не удалось проверить ответ по данным магазина»: сообщите текст вопроса — это сбой проверки, и мы его разберём.
- Сообщения про ключ, бюджет или квоту — это ожидаемое поведение при неверном ключе, исчерпанном бюджете или квоте; приложение не падает.
