## 4. Только на моке или ждёт ключей и аккаунтов
- **Kaspi:** синхронизация, XML, отмены — на моке. Не сверено: лимиты запросов, коды ошибок, формат ответов связей товара (`orderentries/{id}/product`, `merchantProduct`), снятие с продажи на реальном кабинете. `<brand>` не передаётся (решение К-8).
- **Push по складу:** файлы в `outbox/push`, отправки нет (нужны Firebase/APNs).
- **ИИ на сервере:** ключ владелец вписывает сам; до этого помощник работает на правилах.
- **Экраны склада, Kaspi и согласия:** jest-тесты есть, на устройстве не открывались.

## 5. Не работает или с ограничениями
- **EAS-сборка не сделана:** нужен HTTPS-адрес сервера. Для демо на телефоне используется Expo Go с адресом ноутбука в частной сети (`docs/PHONE_TEST.md`).
- **Сервер не развёрнут:** Docker, Caddy и `deploy.sh` не запускались.
- **Не проверено на устройстве:** цепочка приложение → сервер → ИИ → экран; сбои (нет ключа, квота, сеть).
- **Скриншоты магазинов** не сняты.
- **Казахский текст** новых строк не проверен носителем.
- **Остатки Kaspi:** автосписание по заказам работает на моке; на реальном Kaspi не проверено.
- **Частичная отмена старше 14 дней** не подхватывается (решение координатора, К-8).
